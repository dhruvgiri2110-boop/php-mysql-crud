# php-crud-management-system

This is my first PHP + MySQL CRUD mini project. I'm currently learning backend development and this project helped me understand CRUD operations, MySQL integration, and Bootstrap. I know there are many improvements to make (security, prepared statements, better project structure), and I'm working on Version 2.0

In this Project Features are mentioned below:
- Database in Mysql of Clients
- New Client add Button
- Update/edit Client Button
- Delete Client Button
- ID as Primary key and Auto_Increment
- Automatic ID count will start from 1 when, all data will delete.

Technologies Used :-
- PHP
- MySQL
- HTML 5
- Bootstrap (CSS, JS) cdn links
